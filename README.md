## 🚀 How to Host on GitHub Pages (3 Simple Steps)

### Step 1: Initialize Git & Commit
Open terminal in this directory (`d:\Projects\Portfolio`):
```bash
git init
git add .
git commit -m "feat: complete modern portfolio website"
```

### Step 2: Push to Your GitHub Account
Create a new public repository on GitHub (e.g., `muxdaslam-sys.github.io` or `portfolio`):
```bash
git branch -M main
git remote add origin https://github.com/muxdaslam-sys/portfolio.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. On GitHub, go to your repository **Settings** ➔ **Pages**.
2. Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
3. Choose branch: `main` and folder: `/ (root)`.
4. Click **Save**.

Your portfolio will be live at:
```
https://muxdaslam-sys.github.io/portfolio/
```
*(Or `https://muxdaslam-sys.github.io` if your repository is named `muxdaslam-sys.github.io`)*
